# Brain — Learning Knowledge Base (Obsidian vault)

Vault học tập CÁ NHÂN, tách khỏi vault công việc Joy. Mở thư mục này như một vault trong Obsidian.

## Cài 1 lần
1. Obsidian → Open folder as vault → chọn `brain-vault`.
2. Community plugins → cài & bật **Dataview**.
3. Core plugins → bật **Templates** → Template folder = `Templates`.

## Cấu trúc
- `00-Index/` — [[Home]] + [[❓ Questions]].
- `Topics/<Mảng>/` — Frontend, Backend, System Design, DSA, Databases, DevOps & Infra, Security, AI & LLM, CS Fundamentals, Career & Soft Skills, Tools. Mỗi mảng có `_MOC` + `raw/`.
- `Inbox/` — ghi nhanh chưa phân loại.
- `Templates/` — concept / til / gotcha / question / snippet / resource.

## Loại note (`type`)
- `concept` — giải thích một khái niệm (mặc định).
- `til` — "today I learned", một mẩu nhanh.
- `gotcha` — cạm bẫy/điều dễ nhầm.
- `question` — câu hỏi mở → tự lên [[❓ Questions]] (`status: open|answered`).
- `snippet` — đoạn code hữu ích.
- `resource` — link/nguồn cần đọc.

## Dùng
Skill **/note** tự phân loại + tự nhận mảng + ghi vào đây. Hoặc tạo note tay + Insert template.

Khác với:
- **/joy-note** → kiến thức công việc Joy (vault joy-vault).
- **/learn** → học theo lộ trình + theo dõi tiến độ (`~/.learn`).
