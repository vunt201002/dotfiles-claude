🔥 HOT HÔM NAY

  1. Humans missed 1 in 3 threats approving AI agent commands across 40k game runs  (scalex.dev, HN 259↑ 194💬)
     → 409.000 lượt bấm approve/deny thật trong một game mô phỏng: người duyệt sai 1/3
       số lệnh độc. `rm -rf /` thì bắt được 88%, nhưng `npm run analyze` có code
       exfiltrate data vẫn được approve 64.7% — vì không ai đọc phần reasoning phía trên.
       Miss rate tăng dần về cuối phiên = "permission fatigue" có số liệu. Đọc nếu bạn
       ngồi bấm approve cho agent cả ngày.
     https://scalex.dev/blog/ai-agent-permissions-stats/

  2. AMD acquires Taalas to boost inference performance by etching models in silicon  (theregister.com, HN 405↑ 323💬)
     → Taalas nướng thẳng trọng số model vào silicon thay vì nạp từ HBM. AMD mua để đấu
       inference cost với Nvidia. Nếu đúng hướng, kinh tế chạy model sẽ đổi: chip
       chuyên-một-model rẻ hơn GPU đa dụng, nhưng đổi model là bỏ chip.
     https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344

  3. Qwen3.8 Max now ranked as the best overall model by agentic index  (artificialanalysis.ai, HN 447↑ 286💬)
     → Bảng agentic index (đo khả năng dùng tool + chạy task nhiều bước, không phải
       chat) hiện để Qwen3.8 Max đứng đầu. Đáng xem cột giá/token bên cạnh cột điểm —
       đây là chỗ quyết định có đổi model cho agent pipeline hay không.
     https://artificialanalysis.ai/?intelligence=agentic-index

     https://www.rafa.ee/articles/progressive-enhanced-forms-htmx/
