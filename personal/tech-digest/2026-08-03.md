       đáng xem nếu bạn quan tâm binary translation.
     https://github.com/wie-project/kakehashi

  11. F*: A general-purpose proof-oriented programming language  (fstar-lang.org · HN 157↑ 67💬)

       Không phải đồ chơi học thuật: code crypto HACL* verify bằng F* đang chạy trong
       Firefox, Linux kernel, Python, WireGuard; mọi network packet qua Azure đều được
       parse bởi code sinh từ EverParse. TLS 1.3, QUIC, Signal cũng có bản verified.
     https://fstar-lang.org/
