🔥 HOT HÔM NAY
  2. The git history command  (HN 280↑ 161💬)
     → Git sắp có lệnh `history` built-in (bản 2.54/2.55): `fixup` gập commit cũ + tự
     rebase mọi branch con, `reword` sửa message mà không cần checkout, `split` tách 1
     commit làm 2 bằng chọn hunk — tất cả atomic, không bao giờ để repo ở trạng thái vỡ.
     Lấy được phần lớn lợi ích của `jj` mà không cần đổi workflow.
     https://lalitm.com/post/git-history/

  3. Building and shipping Mac/iOS apps without opening Xcode  (HN 463↑ 199💬)
     → Toolchain cụ thể: XcodeGen sinh `.xcodeproj` từ `project.yml`, `xcodebuild` +
     `notarytool` + `codesign` chạy CLI thuần, gói hết vào 1 script `release.sh`. Điểm
     hay nhất: tác giả để Claude Code tự chạy + maintain script build qua CLAUDE.md —
     một ví dụ thực tế của agent-driven release pipeline, không chỉ code.
     https://scottwillsey.com/building-and-shipping-mac-and-ios-apps-without-ever-opening-xcode/
