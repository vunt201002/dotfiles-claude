  3. ChainDrop supply chain compromise: Anatomy of a self-propagating worm  (Microsoft Security, 04/08)
     → Teardown kỹ thuật của Microsoft về vụ npm 400+ package: worm dùng
       preinstall hook, tải Bun runtime rồi chạy stealer đi quét .npmrc token,
       GitHub CLI token, AWS credentials, kube config. Tự lây bằng cách liệt kê
       package mà identity bị chiếm có quyền, nhét malware vào tarball, tăng
       patch version rồi republish. Phần hành động cụ thể: lên npm CLI v12 để
       dùng `min-release-age`, pin version, purge cache, rotate credential từ
       máy sạch.
     https://www.microsoft.com/en-us/security/blog/2026/08/04/chaindrop-supply-chain-compromise-anatomy-self-propagating-worm/
